## Secret Manager

| AWS                                 | Azure                                              | Purpose                                                              |
| ----------------------------------- | -------------------------------------------------- | -------------------------------------------------------------------- |
| AWS Secrets Manager                 | Azure Key Vault                                    | Store secrets, passwords, API keys, connection strings, certificates |
| AWS Systems Manager Parameter Store | Azure App Configuration (or Key Vault for secrets) | Store application configuration and parameters                       |
| IAM Roles                           | Managed Identity                                   | Authenticate to Key Vault without storing credentials                |
