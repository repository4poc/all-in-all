## CloudFormation

![alt text](images/{6030C17C-1D0E-469E-92A8-373954C776D7}.png)

| AWS                                  | Azure                                               | Purpose                                       |
| ------------------------------------ | --------------------------------------------------- | --------------------------------------------- |
| AWS CloudFormation                   | Azure Resource Manager                              | Deploy and manage infrastructure as code      |
| CloudFormation Templates (JSON/YAML) | ARM Templates (JSON)                                | Declarative infrastructure definitions        |
| AWS Cloud Development Kit            | Azure Bicep                                         | Simpler syntax that compiles to ARM templates |
| CloudFormation Stack                 | Resource Group Deployment / Subscription Deployment | Logical deployment unit                       |
| Stack Update                         | Incremental or Complete Deployment                  | Update existing infrastructure                |
| Stack Drift Detection                | What-if Deployment + Resource Graph + Policy        | Preview and detect configuration differences  |

## AWS CDK Constrcts

There are 3 level of CDK constructs

- L1 Level Constructs : Cfn (Cloud Formation) Resources, when used, we must configure all properties
- L2 Level Constructs : Mostly Used, Provide typesafety and abstraction
- L3 Level Constructs : Called Patterns, combile multiple AWS resources, like LambdaRestAPI

## AWS CDK Outputs

- Used to share information about resource to other resources.

If we generally output the resource properties, it will print token, instead od the actual value.

![alt text](images/{F203130E-E5CC-4E1F-AC53-19D1D3E88D36}.png)

Solution : Use CDK output

```
new cdk.CfnOutput(this, "QueueURL", {
    value: queue.queueUrl,
    description: "The URL of the SQS queue",
});
```

## CDK Deployment Parameters

```
    const queueNameParameter = new cdk.CfnParameter(this, "duration", {
      type: "Number",
      default: 120,
      minValue: 60,
      maxValue: 10 * 60,
      description:
        "The duration in seconds for the SQS queue visibility timeout",
    });

    new cdk.CfnOutput(this, "durationValue", {
      value: queueNameParameter.valueAsString,
      description:
        "The duration in seconds for the SQS queue visibility timeout",
    });
```

```
$ cdk synth --parameters duration=50
Unknown option(s): --parameters. These will be ignored. Run 'cdk --help' to see available options.


cdk deploy --parameters duration=60
```
