## CloudFormation

![alt text](images/{6030C17C-1D0E-469E-92A8-373954C776D7}.png)

| AWS                                  | Azure                                               | Purpose                                       |
| ------------------------------------ | --------------------------------------------------- | --------------------------------------------- |
| AWS CloudFormation                   | Azure Resource Manager                              | Deploy and manage infrastructure as code      |
| CloudFormation Templates (JSON/YAML) | ARM Templates (JSON)                                | Declarative infrastructure definitions        |
| AWS Cloud Development Kit            | Azure Bicep                                         | Simpler syntax that compiles to ARM templates |
| CloudFormation Stack                 | Resource Group Deployment / Subscription Deployment | Logical deployment unit                       |
| Stack Update                         | Incremental or Complete Deployment                  | Update existing infrastructure                |
| Stack Drift Detection                | What-if Deployment + Resource Graph + Policy        | Preview and detect configuration differences  |

## Working with CDK

![alt text](images/{26DBD657-9BC1-4C41-8FE5-EF666ED7988C}.png)

```
aws sts get-caller-id

aws configure get region
```

```
cdk bootstrap

```

This bootstrap the CDK project by creating the basic resources in AWS

- Creates S3 bucket
- Create ECR repository
- Create CloudFormation Stack
- Create Few Roles

## Define resources in CDK

Resources are defined in lib folder
![alt text](images/{0A991F9A-25B8-47CB-BB66-0CF246F93739}.png)

```
cdk synth
```

This command generate/override the CloudFormation Template in `cdk.out`, without deploying it onto AWS
