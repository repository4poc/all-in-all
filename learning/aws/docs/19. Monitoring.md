## Monitoring in AWS

![alt text](images1/{DD5D68F4-50C4-4AC7-BC15-F38E70ED4CD7}.png)

| AWS                       | Azure                              |
| ------------------------- | ---------------------------------- |
| CloudWatch Metrics        | Azure Monitor Metrics              |
| CloudWatch Logs           | Log Analytics Workspace            |
| CloudWatch Dashboard      | Azure Monitor Workbook / Dashboard |
| CloudWatch Alarms         | Azure Monitor Alerts               |

| X-Ray                     | Application Insights               |

| Trusted Advisor           | Azure Advisor                      |
